# ses-grubu-metin · çekirdek cümle sözlüğü
# Biçim: <tür> <boşluk> <kelime>
# Her kelime tek türde bulunur. Türler:
#   kisi            tekil insan özne (okuma/yazma yapabilir)
#   hayvan          tekil hayvan özne (okuma/yazma yapmaz)
#   yiyecek         yenebilen nesne
#   icecek          içilebilen nesne
#   okunacak        okunabilen/yazılabilen nesne
#   esya            elde tutulan, atılan oyuncak/araç
#   zarf            -e durum ekli yer zarfı ("eve", "okula")
#   fiil            3. tekil, nesnesiz eylem
#   gidis           3. tekil, yer zarfıyla kullanılan eylem
#   yeme/icme/okuma/yazma/tutma/atma/sevme
#                   3. tekil, yalnız eşleştiği nesne sınıfıyla kullanılan eylem
#   emir            emir kipi, nesnesiz
#   emir_gidis      emir kipi, yer zarfıyla
#   emir_yeme / emir_icme / emir_okunacak / emir_esya
#                   emir kipi, yalnız eşleştiği nesne sınıfıyla
